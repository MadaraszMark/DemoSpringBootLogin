# Spring Boot Login Alkalmazás  

## Áttekintés  
Ezt az alkalmazást gyakorlásképpen hoztam létre, legelső Spring Boot-os próbálkozás.

#### Fő Funkciók:
- Regisztráció.
  - Karakterenként ellenőrzi, hogy foglalt-e a felhasználónév, vagy szabad.
  - E-mail cím formátum ellenőrzés
  - BCrypt jelszóvédelem
- Belépés
- Modern UI
  - Reszponzív felület

### Előfeltételek:
- Java 8 (JavaSE - 1.8)
- Maven
- Spring Boot
- JavaFx
- MySQL
